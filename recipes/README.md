# Recipes — dishes, scored

Two folders, with a one-way, by-hand promotion between them:
- `candidates/` — untested ideas, including anything the workflow generates.
  Scored against the four principles, but unproven.
- `proven/` — recipes I've tested and keep making. I move a recipe here myself,
  once I've cooked it and it earns its place. Never automatic.

Each recipe is judged on the four principles (`../CLAUDE.md`) and built from
top-ranked `../ingredients/`. Format:

```
## Name
**Nutrition** 🟢 · **Effort** 🟢 (active ~Xm · N session · ~Ym total) ·
**Availability** 🟢 · **Taste** 🟢
**Equipment:** pot / pan / knife
**Serves:** N

One or two lines on the dish.

### Ingredients
- ... (mark optional / substitutes)

### Method
1. ...

**Why it scores well:** ...
**Levers:** flavour or variation tweaks.
```
